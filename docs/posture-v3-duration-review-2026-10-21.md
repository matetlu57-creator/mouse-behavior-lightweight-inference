## 规则与接口边界

两类各自使用 1.2 秒中心测量窗口、0.1 秒步长；边缘窗口至少 0.4 秒。关键点置信度 ≥0.8，检测置信度 ≥0.4；窗口有效比例 ≥0.7；投票支持 ≥0.15、至少两个正窗口；连续候选事件 ≥0.3 秒。片段候选占比 15% 是包中诊断标签条件，不能用来代替独立事件时长。

| 类别 | 冻结的主要证据 |
|---|---|
| Grooming | 身体坐标内头相对颈幅度 ≥0.026531L；反向运动 ≥2/s；鼻耳一致性 ≥0.481215；后躯范围 ≤0.075267L；相对运动占比 ≥0.711642 或弯曲脊柱；另有背部重复动作分支 |
| Rearing（站立含扶墙） | 相对运动占比 ≤0.594252；颈相对后躯范围 ≥0.064025L；脊柱方向余弦 ≥0.967879；投影半径变化 ≥0.033314L；头颈同动 ≥0.7；形变/后躯平移比例 ≥2.914367 |

L 是独立输入或当前片段鼻颈长+颈尾长的 Q90 投影代理，不是真实身高。周期性附加门在该冻结操作点中为零（关闭），未宣称周期性已改善准确率。

## 审查发现与修复

1. 角色翻转拆分后没有重新检查连续时长：已修复，过短子段不输出。
2. 上下文核心裁剪可生成过短独立片段：已修复，仅保留真实完整达标父事件或拒绝。
3. 编码前后只查帧数、未核对规则时长：已补编码前预检与实际解码 FPS 的复核。
4. 多窗口恢复完整父事件后，同 ID 的理毛/站立可能重叠：独立审查复现后修复，全视频按原始候选区间解析冲突并重验时长。
5. 自定义更长时限可能被默认导出阈值放行：已修复，有效配置贯穿识别、裁剪、合并、导出与元数据。
6. 真实画面目标框不醒目：改为绿色粗框和 ID/行为标签；缺失目标不伪造框。

独立审查最终无 BLOCKING；另用 1,000 组随机区间与逐帧集合参照核验跨窗口冲突算法。

## 运行方式

已有视频+元数据+轨迹样本，指定原始视觉 ID（可重复 `--track-id`）：

```powershell
python scripts/review_posture_sample.py --sample <样本目录> --track-id <视觉ID> --output <全新输出目录>
```

完整视频走现有已绑定来源和模型的 pose cache：

```powershell
python scripts/run_canonical_behavior_video.py --video <源视频> --pose-cache <缓存目录> --source-receipt <来源绑定JSON> --posture-mode v3_review --output <全新输出目录>
```

默认正典仍停用这两类；显式 `v3_review` 才产生待审核姿态候选。输出不能自动增加人工 A1 或改变 A2。

复现 176 段回放：`scripts/audit_posture_v3.py --manifest <冻结split_manifest_v31.json> --baseline-results <原包results_v31目录> --output <全新目录>`。
