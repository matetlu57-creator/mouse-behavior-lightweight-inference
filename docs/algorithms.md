# 算法说明

轻量路径是基于缓存的行为分析路径，不是完整遮挡恢复和 ReID 管线的替代实现。

## 处理阶段

1. 读取已经完成的 YOLO Pose 缓存，并规范化帧、关键点、框和有效检测；
2. 学习当前视频的小鼠笼子范围和像素到厘米的尺度；
3. 使用距离、朝向和有效性预筛选有价值的候选鼠对；
4. 只对候选时间窗计算 Pair 运动学、鼻体几何和 rolling features；
5. 独立生成鼻头、鼻尾接触事件；
6. 使用标准证据和标准 FSM 判断追逐、攻击；
7. 使用并行 FSM 处理个体、社交、接触和群体行为；
8. 对满足窄门槛的短回避候选执行恢复，对短攻击候选增加跨帧可靠性确认；
9. 输出事件 CSV、网站导入包、统计报告和渲染视频。

## 行为判定边界

### 追逐和攻击

标准行为引擎只把 chase 和 attack 作为基础因果行为类别：

- 追逐需要持续的距离、速度、朝向和追随关系；
- 攻击在北医 profile 中优先使用检测框的接触/重叠、框中心快速位移、面积变化和
  前后框 IoU 突变；关键点动作和目标反应是加分证据，不再要求被遮挡的鼻头关键点
  一直可见；
- 骑乘或扭打造成短暂漏检时，跟踪层最多保持配置的 12 帧框级遮挡桥接。桥接框只
  参与攻击的框接触和运动证据，并标记为 `bbox_imputed`；普通关键点轨迹、个体
  行为、鼻体几何和群体人数仍只使用真实观测；两只小鼠同时消失时不会用两个 stale
  框触发攻击；
- 攻击恢复分支还需要高分、接触几何、原始速度和冲击或反弹方向；检测框证据也必须
  在短窗口内重复出现，避免一次 ID 交接或框抖动触发攻击；
- 任何进入行为 CSV 的攻击至少需要两个分析样本在短窗口内相互支持；单帧攻击
  候选会被抑制，不再作为可靠攻击渲染或导出；
- 普通鼻头或鼻尾接触不会自动升级为攻击。

渲染器根据 actor_id 和 target_id 分别显示主动方和被动方，不用整帧统一标签。

### 个体、社交和群体行为

- 个体行为使用每只小鼠的稳健速度和连续时间窗识别 running、walking、
  stationary；
- 社交行为使用鼠对距离变化、速度、追随和逃逸方向识别 together、approach、
  avoidance；
- 群体行为使用当前帧有效小鼠的邻域和局部连通分量识别 huddle、isolation。
  huddle 不是“任意三只相互接近的小鼠”或一条近邻链：默认要求至少三只小鼠，
  每只成员在同一局部核心内至少有两个邻居，并通过持续时间门。距离阈值是单条
  局部邻接边的上限，不要求大型群体中所有两两中心距离都小于阈值；因此远端
  对角成员不会因为彼此距离较远而使整个扎堆失效。默认使用 local 密度支持度，
  旧的全局 all-pairs 密度可以通过 `huddle_density_mode=global` 兼容启用，
  full-clique 也仍可显式开启；
- 通用 profile 的邻接距离默认为 5 cm，北医 profile 则根据四个 huddle 正向样例的
  稳定三鼠核心距离标定为 11 cm。北医关闭体长二次上限，避免白鼠和黑鼠混合时由
  中位体长把固定空间阈值错误缩小；两只小鼠的接近仍保留为社交行为；
- 当前轻量路径使用同一视频共享的稳健体长尺度，不给白鼠和黑鼠分别建立厘米坐标，
  这样不会产生同一画面内的坐标系不一致。由于尚未提供笼子实际尺寸或静态透视
  标定，该厘米值仍是近似尺度；需要绝对物理距离时应使用固定相机标定，而不是按
  小鼠个体体型分别缩放；
- 群体事件记录 member_ids 和 member_ids_at_peak，渲染和网站导出只使用真实参与者。

北医 profile 的持续时间门与规范保持一致：running 至少 0.5 秒，walking 和
stationary 至少 1 秒，together 至少 1 秒，chase 至少 2 秒，nose-tail contact
至少 0.5 秒，huddle 至少 1 秒。规范未给出接近、回避、攻击和鼻头接触的固定
持续秒数，因此 profile 对这些行为统一增加至少 1 秒核心证据门；攻击还保留
“明确冲突证据 + 至少两个分析样本支持”的可靠性门。孤立行为按当前项目规则
至少 3 秒。北医 huddle 的距离阈值已经单独使用四个正向样例进行标定；其它速度
和距离条件仍作为算法内部证据使用，但不把它们与文档数值的完全相等作为通用验收
条件。

这些通道并行运行，事件 CSV 保留各通道的原始证据。渲染器再按每只小鼠执行
“群体行为 > 社交行为 > 个体行为”的显示覆盖：参与 huddle 的小鼠显示“扎堆”，
参与 isolation 的小鼠显示“孤立”，同一只小鼠不再同时显示较低层级的鼠对或个体
标签；未参与群体事件的小鼠仍可显示自己的社交或个体行为。不能用一个全局群体
标签覆盖所有 ID。社交层内部以“接近”为最高显示优先级；它表示由远到近的前置
阶段。接近结束后，事件可以转入“一起”“回避”或“接触”，而不是把这些并行证据
同时覆盖到同一只小鼠上。追逐和攻击仍是社交层的独立事件，保留在接近之后的社交
优先级中；显式渲染 focus 只用于同层的指定行为复核，不会越过群体层覆盖规则。

## 短事件恢复

普通 FSM 仍然保留最小持续时间和短间隙规则。对于北医示例中只有少量分析帧但证据
完整的行为，独立恢复分支可以输出短事件；攻击恢复不接受孤立单帧：

- 短攻击：要求接触、攻击分数、动态证据、角色可信度、原始攻击者速度，以及
  发起冲击或目标反应的一组方向条件；
- 短回避：要求接近后的距离增加、目标逃逸方向、目标和攻击者速度，以及前置接近
  证据；
- 北医 profile 允许回避事件在短暂遮挡后的相邻身份片段之间进行受限拼接；拼接必须
  有共同身份、时间间隔和参与者数量上限，通用 profile 默认不启用该恢复；
- 通过 event_recovery 区分普通 FSM 事件和恢复事件；
- analysis_* 和 core_* 保存实际证据，start_frame 与 end_frame 只增加有限前后文
  供渲染和切片使用。

恢复规则只看轨迹和特征，不读取视频文件名或文件夹名。

## 北医重点渲染

北医目录名称可以作为人工验证清单中的期望重点，传给渲染器后只影响右侧面板的
持续重点标题，不参与行为推理。这样可以让重点提示贯穿整段视频，同时保留真实
事件覆盖作为独立指标，避免把显示上下文误当成逐帧真值。

渲染日志中的 `persistent_display_coverage` 是重点提示的显示覆盖；
`evidence_coverage` 是事件 CSV 中该行为真实 `start_frame` 到 `end_frame` 的覆盖。
前者指定重点时可以达到 1.0，后者必须使用逐帧人工标注才能判断准确率。

## 并行 FSM

parallel_behavior_fsm.enabled 默认开启。个体、扩展鼠对、接触和群体行为各自
使用独立区域，互不因为另一个区域已经触发而全局隐藏。标准追逐/攻击 FSM 具有
独立的因果状态机，不受普通接触事件直接触发。

当前唯一支持的执行模式是 active。关闭并行 FSM 时，标准追逐/攻击仍可用，但
个体、扩展鼠对、接触和群体区域事件不会输出。

## 验证边界

北医样例验证目前是视频或文件夹级覆盖检查，并额外报告核心事件持续时间。覆盖率
为 1.0 说明示例视频出现了期望标签，不代表逐帧 Precision、Recall、F1 或
actor/target 准确率。对规范没有明确固定时长的接近、回避、攻击和鼻头接触，北医
profile 统一执行至少 1 秒核心证据门；孤立按当前项目规则执行至少 3 秒核心证据
门。脚本会把核心证据不足与视频上下文不足分开报告，不会用渲染前后文替代行为
持续时间。
阈值变更后，必须同时运行：

1. 相关单元测试和集成测试；
2. 冻结输出或回归夹具比较；
3. 北医示例覆盖验证；
4. 有帧级标注时的 Precision、Recall、F1 和角色准确率评估。
