# Sealed execution policies and media boundaries

Status: accepted for the audit repair.

## Context

Arbitration and video-window clipping could retain event fragments without the
endpoint evidence that qualified their parent. Media recropping copied current
claims from old annotations. Legacy rendering checked identity mapping without
proving that source video, cache and events belonged to the same analysis.
Historical rerendering also consumed current default duration policies while
retaining an earlier rule receipt.

## Decision

Requalify residual Approach spans and preserve complete qualified parents when
core clipping would remove Approach/Dispersal semantic endpoints. Keep measured
role intervals rather than selecting a direction for an entire event.

Discover Dispersal origins from observed formations and keep their admission
clocks independent. Raw adjacency reconnections do not end a departure. A
successor requires an observed departure-attempt boundary; an unobserved end
waits for an observed return or the existing measured inactivity condition.
Short attempts may close without qualifying as a behavioral event. Partial
regrouping does not retire an entire larger origin, and genuine reformations
may occur at a new location. Final event duration and geometry gates are unchanged.

Bind source bytes, cache chunks and analysis CSVs before lightweight rendering.
Canonical historical reuse additionally requires a portable source dependency
snapshot and the live effective/default rule configuration to match. Reject an
incomplete or changed historical snapshot rather than pretending to execute an
old rule implementation. Fresh inference over an independently verified existing
pose cache is the migration path; no new tracking identities are manufactured.

Reconstruct current annotation claims during recropping. Retain old claims only
in provenance. Verify decoded media before final publication and keep failures
out of completed manifests.

## Consequences

Some previously accepted digest-free caches and historical rerender receipts now
fail with actionable migration errors. This is intentional compatibility
tightening. Raw source data and prior outputs are never rewritten. Complete
qualified parents may extend beyond one inference core, and retain explicit
reason flags for audit and deduplication.

This establishes provenance and interval integrity. It does not establish
biological identity, scientific classification accuracy, or new pause/isolation
semantics. Those require their respective evidence and validation contracts.
