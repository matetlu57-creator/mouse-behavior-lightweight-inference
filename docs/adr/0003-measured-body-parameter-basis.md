# 0003：实测长宽参数基准与静止的局部头部运动

- 日期：2026-10-05
- 状态：已实施参数迁移；新的数据集训练和精度验证待执行

## 背景

用户补充旧行为参数对应约 8 cm 体长、3 cm 体宽，并要求按实测约
10.7 cm 体长、4.15 cm 体宽更新参数。用户同时明确：静止允许头部左右
转动和探索，不能要求小鼠的所有关键点都静止。

当前轨迹尺度已经调用标定鼻头到尾基参考体长 10.7 cm。
标定平均髋宽为 4.1467 cm；导出轨迹原来的缺失宽度兜底却仍为 2.4 cm，
群体形态兜底还使用躯干长度的 30%。不能再次放大已经换算的轨迹。

## 决策

1. 本轮按保持旧参数相对于身体大小的边界处理，包括此前 v4 的距离和速度规定。
   默认 YAML、Beiyi profile、Core/ethogram/exported 三套规则的活动物理参数、
   ranker 候选参数库一次性乘以 10.7/8 = 1.3375。
   cm/s² 加速度也乘该一次系数；只有 cm² 面积才乘系数平方。
   群体规则默认速度、接触特征固定距离以及标准分析链路的活动物理兜底也同步迁移，
   避免完整配置与缺省调用采用两套标尺。
   ethogram 的内置默认先与旧 default.yaml 对齐，再迁移：例如旧配置的
   Approach terminal 为 5 cm，而源码兜底为 17 cm；当前统一为 6.6875 cm。
   Together 最大距离的旧配置为 6 cm、源码兜底为 8 cm，当前统一为 8.025 cm。
   显式自定义 terminal 参数仍按传入值读取，保留对应回归测试。
2. 时间、角度、余弦、比例及体长/体宽倍数保持。已经废弃、仅用于旧模型
   构造兼容的字段保留原值，规则继续不读取它们。
3. 坐标和轨迹特征不再次缩放；显式传入的物理参数按原值消费。
   `behavior_parameter_units` 是来源记录，不参与运行时乘法。
4. Static 和 Locomotion 消费身体中心平移速度。头部转动或朝向变化本身
   不构成理毛或站立证据。现有中心算法已排除鼻/耳运动，本轮增加该语义的
   回归保护，保留独立的 rearing/grooming 证据槽位及其优先级。
5. 观测到的髋宽/耳距仍优先使用，均缺失时从标定记录取得 4.1467 cm；
   `scale.assumed_mouse_body_width_cm` 仅作缺少标定宽度时的显式兜底。
   旧的显式自定义配置若既无标定宽度也无该键，保留原比例兜底以兼容。
6. 新种子为 `configs/exported_heuristic_parameters_measured_body_v3.json`，
   旁边的 `.meta.json` 保存哈希、尺度与状态。旧参数 JSON、训练模型、缓存
   和报告保持历史口径，不能直接把其指标解释为新参数结果。

## 备选方案与影响

若行为距离原本是尺寸无关的实物厘米规定，就应保留数值；本轮依据用户明确
说明旧数值针对 8×3 cm，采用身体比例迁移。该操作是新标尺下的参数初值，
不是重新训练所得的最优阈值。体宽比不应用到全部场地坐标。

Core 与输出/导出适配器原有平滑与速度边界保留，各自的静止速度分界分别为
0.66875 和 13.375 cm/s，不能把此次单位迁移描述成两条路径已经完成统一标定。
历史调参脚本的试验网格和旧模型需在新版本重建中重新审查、训练；本轮不以
人工审计批次做参数搜索，也不声称全数据集精度提升。

## 验证

回归测试使用身体稳定而鼻/耳快速旋转的合成轨迹，分别验证 Core、主输出和
导出适配器仍形成 Static；同样转头但身体平移的对照必须形成 Locomotion。
同时检查新阈值、持续时间/角度不变、无二次换算、非法宽度拒绝和缺失宽度兜底。
既有接触、追逐、扎堆、聚集、分散和群体运动的正负断言继续保留。
