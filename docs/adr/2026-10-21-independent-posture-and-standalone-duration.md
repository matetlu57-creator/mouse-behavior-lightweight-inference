# 独立姿态候选与独立视频时长验收

日期：2026-10-21。状态：已实现，审核候选通道；未通过科学识别能力验收。

## 背景与决策

用户提供的 V3 压缩包已将 Grooming/Rearing 的行为参数、评分、参数选择和候选事件拆开。该包的负例验证仍显示低精确率，旧会话 Rearing 召回为零。接入任务不能据此自动赋予正式标签或人工审核信用。

采用包内冻结的 V3.1 class-balanced 配置，移植测量、独立规则和适配器三个模块。不得在接入时重新寻优或以另一行为的失败推断本类成立。冲突解析只能影响最终唯一标签，不能改写两类原始候选。Rearing 沿用站立类，包括扶墙站立，不新增 Climbing 类；七点二维投影不能证明离地高度或扶墙接触。

视频管线增加显式 `--posture-mode v3_review`，缺省正典停用策略保留。输出统一 `requires_review=true`，不读 annotation 或人工审核结果进行推断，不修改数据集或 A1/A2。审核通道允许生成两类视频、三份 JSON 和完整证据日志。

共享测量依赖是公开的：置信度、坐标、尺度会影响两类；各类行为阈值及时间窗口独立。同一视频不同上下文可能产生边界差异，因此最终采用按原始视觉 ID 的两类候选区间并集，全视频移除争议重叠，再分别检查连续片段时长。保留原始窗口日志，不以填帧连接缺失或补长事件。

## 视频时长契约

独立行为包使用源帧半开区间 `[start_frame,end_frame)`。角色拆分、上下文裁剪及最终事件合并均检查时长。核心窗口产生过短子片段时，仅允许保留真实且完整达标的父事件；否则拒绝。父事件不是任意扩展上下文的许可。

统一时长策略读取有效规则配置，保留 `>` 与 `>=` 的区别；同步运动还检查实际同步支持区间的并集。运行配置的有效参数写入并绑定 `input_binding.json`，导出端重建类型化参数，不接受事件自填阈值。姿态 V3 两类均为 ≥0.3 秒，未标记 V3 的旧 Rearing 策略仍为 ≥0.5 秒。

批次导出前预检，编码后以实际解码帧数/编码 FPS 再验收。通过后才发布 annotation、metadata、tracks。旧固定时长展示裁剪保留 `fixed_window_showcase` 标记，不能视作已满足行为规则的独立事件。

## 后果与边界

优点是原始候选可追溯、冲突可见、规则参数相互独立、导出时长可证伪。保留完整父事件可能使视频包超出核心处理窗口，日志明确记录此情况；有限上下文仍不能保证无限历史行为边界。原始视觉 ID 不等于生物学身份，不跨 ID 合并。

176 段冻结模型回放检验移植一致性，不能充当新的折外或独立验证。完整质量门与视频解码成功也不能证明分类准确。正式启用两类仍需要有效的行为证据和人工审核验收。
