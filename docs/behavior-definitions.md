# 三层小鼠行为学规则

新规则核心消费统一后的厘米轨迹。尺度政策（2026-10-05 起，默认 `scale.mode: body_length`）：每个视频在分析时以自身鼻头到尾基像素长度的中位数（经鲁棒参考剔除姿态坏轨）调用统一实测体长 10.7 cm（唯一权威记录 configs/scale/rig_a.json 的 subject_metrics；config 键仅作兜底）换算 cm_per_pixel，其后所有距离/速度分析消费该逐视频尺度；`scale.mode: calibration` 保留为 rig 级固定尺度/homography 手动覆盖（1 m x 1 m 内径场地标定是 10.7 cm 的测量来源，实测与逐视频尺度在该 rig 上偏差 <1%）。鼠宽优先用可靠帧的左右髋距离中位数估计，缺失时回退耳距，均缺失时使用标定平均髋宽 4.1467 cm；扎堆距离按体宽比表示。所有 ID 都是视觉 track ID；规则不从坐标、颜色、亮度或行为推断 RFID/生物学身份。

## 2026-10-05 v6 裁剪规则更新（用户最新反馈优先）

本轮用于既有数据集的逐帧初筛和视频裁剪；以下规则覆盖旧裁剪口径。主 Top-1 历史模型的阈值表保留为旧实现记录，不能用来解释当前筛查输出。

已有人工审计回放仍显示自动理毛/站立区分不可靠。因此 `ScreenPolicy.posture_export_mode` 默认 `human_confirmed_only`：正式姿态视频只导出既有人工明确确认的 4 个理毛、8 个站立；`plan.jsonl.posture_probe_windows` 保留自动候选供复核。原数据源标签不限 Static，但必须有确切人工结论和真实视觉 ID。下列姿态条件仅用于候选探针，不代表已通过准确率验证。

- 接近：鼻头到对方身体关键点凸包表面的距离，与鼻头到关键点的距离分开处理。前者以 0.1 个实测体宽（缺宽时约 0.415 cm）为接触容差，不再套用 2.675 cm 关键点接触阈值；用户明确要求鼻头到对方身体表面约 3.5 cm 时截断（用户在 3 cm 基础上再增加 0.5 cm）；取消额外提前 0.15 s 截断和 0.15 体宽余量。跨界前后两帧取更接近 3.5 cm、未实际接触的真实帧；最终端点误差不得超过 0.5 cm。未到达边界或跨界两帧都太远的原片不作完成接近导出；不保留后续离开。
- 追逐：允许运动过程中鼻尾接触；鼻头接触仍排除。高速种子仍要求两鼠速度各 ≥26.75 cm/s，中心距离 ≤16.05 cm，输出连续至少 1 s。领先鼠转弯与追鼠到达弯道可以有最多 0.5 s 的时间差，必须保持追鼠前方关系或与领先鼠历史路径相距 ≤0.5 体宽，运动方向 cos≥0.707。种子间最多 0.4 s 的下降仅在双鼠速度各 ≥10.7 cm/s、几何和追随关系持续成立时连接；不补真实停顿、相向或缺失帧。
- 理毛：头部相对颈部的重复前后运动，鼻耳协同，后躯稳定；整个鼻、耳、颈一起起伏不作理毛证据。背部理毛继续检查扭头进入后躯区域并重复动作。部分站立时确有理毛动作仍属理毛。
- 站立：小幅头颈相对运动与躯干短缩，并要求邻接 2 s 有至少 25% 躯干伸展变化作为额外证据；整段恒定蜷缩静止不输出站立。爬墙与空地模式仍分别记录。单凭二维关键点无法保证离地，自动输出均为待复核候选。

## 分层语义

| 输出层 | 行为 | 目标数量 |
|---|---|---:|
| 个体（底层） | Locomotion（移动）、Static（静止）；Grooming（理毛）、Rearing（站立攀爬）槽位已建、检测器待 Step 5-A 标定启用 | 1 |
| 社交（中层，包含/伴随个体状态） | Approach、Together、Chasing、Attack、Snout-head contact、Snout-rear contact（Avoiding、Following 自 2026-10-04 Step 3 暂停） | 2 |
| 群体（顶层，包含/伴随个体与社交状态） | Huddling、Social clustering、Dispersal、Group locomotion | ≥3 |
| 群体空间关系（顶层目标事件） | Isolation | 1 个被判定孤立的目标；判定需与场景中的其他鼠比较 |

一段轨迹可以同时具备低层运动证据和高层事件证据。每只鼠始终保留个体状态，社交事件和群体事件也独立保存；`primary` 仅选该鼠当前最高有效层级，不删除低层事件。社交/群体候选只影响其成员 ID，不相关的群体不能覆盖另一对鼠的社交事件。移动/静止以身体中心的平移速度互斥判定；静止允许头部左右转动、抬头探索和局部微动。鼻头速度或朝向变化本身不能触发移动、理毛或站立。理毛/站立须有独立证据，证据不足或配置重叠时报 Unknown/配置错误。社交同层按语义特异性解析，Attack、持续接触高于 Chasing、Approach、Together（Avoiding、Following 已暂停，不参与解析）；群体同层按 Huddling > Social clustering > Dispersal > Group locomotion > Isolation 解析。

项目内规则核心位于 `src/mouse_behavior/behavior/hierarchical_core.py`。它只接受统一的 Feature Object（距离 cm、速度 cm/s、时间 s），不从视频像素自行定义另一套单位；配置入口是 `hierarchical_heuristic_core`。主行为输出层在 `ethogram.py` 中执行相同语义，Together/Huddling 均无速度门；离线导出数据集适配器在 `evaluation/exported_dataset.py` 中使用相同的行为语义。由于不同适配器的速度平滑方式不同，阈值仍需按数据集复核，不是跨场地的已验证生物学常数。

## 个体行为

| 行为 | 可执行判据 | 最短持续时间 |
|---|---|---:|
| ［Step 4 合并］Locomotion | 身体中心平移速度高于静止上限即移动（原 Walking+Running 合并）；允许不超过 0.5 s 的短暂停顿间隔；理毛/站立攀爬证据门启用后以负定义排除 | 0.5 s |
| Static | 身体中心平移速度不超过适配器的静止上限；一个片段内中心半径 ≤1.3375 cm。允许完整观测下 ≤0.2 s 的短暂挪动，但该片段的最大位移也须 ≤1.3375 cm；允许头部左右转动和有限抬头探索 | 1 s |

短暂挪动的上限复用已标定的 0.2 s 缺口和 1.3375 cm 中心稳定半径；超时、缺帧、超出位移/半径或持续漂移都不能并入 Static。当前 extended ethogram / 导出适配器的速度上限仍为 13.375 cm/s，分层 Core 的静止速度上限为 0.66875 cm/s；这些适配器因平滑口径不同暂未统一，新增的短时位移和空间限制在两条逐帧适配器中一致执行。配置键为 `extended_behavior.individual.stationary_transient_max_duration_seconds`（0.2）、`stationary_transient_max_displacement_cm`（1.3375）、`stationary_max_center_radius_cm`（1.3375）；Core 汇总窗还要求调用方提供独立测得的短暂运动时长与位移。

头部左右转动、鼻耳速度或朝向变化本身不构成移动、理毛或站立。当前顶视二维关键点不能直接测真实抬头高度，因此有限抬头探索以投影姿态作人工复核边界：若鼻尾投影长度 ≤参考体长的 78%（10.7 cm 参考体长下约 8.35 cm），并且相邻 2 s 出现 ≥1.25 倍的躯干伸展恢复，应从 Static 转站立攀爬人工复核；这组线索仍是候选而非自动真值，理毛/站立攀爬主检测门继续关闭。没有上述组合证据时，单独抬头和头部转向可保留在 Static。

## 社交行为

| 行为 | 判据 | 最短时长 |
|---|---|---:|
| Approach | 接近鼠鼻头到被接近鼠最近关键点的距离：起点 ≥6.6875 cm、终点 >2.675 cm（接触即截断）；接近鼠速度 >4.0125 cm/s 且 closing ≥2.675 cm/s；表现为无实质性接触 | 训练校准；不能低于 0.1 s |
| Together | 恰好 2 只；中心距离 4.0125–8.025 cm 带；允许接触（无互动）；无速度门；互动帧（Attack/Chasing）不计入 | 1 s |
| Chasing | 两只鼠中心距离 ≤16.05 cm、双鼠速度 ≥26.75 cm/s、方向 cos ≥0.707、全程零接触（硬性）；仅真 dropout ≤0.5 s 可桥接 | 1 s |
| ［暂停 2026-10-04 Step 3］Avoiding | 必须先有接近/近距离背景；随后至少一只鼠加速逃离，双鼠距离持续增加 | 训练校准；不能低于 0.5 s |
| Attack | 扑击/咬合/纠缠的近距离接触和快速运动；鼻头关键点加速度 ≥66.875 cm/s² 作为轻度攻击（攻击下限）与纯接触区分；同一视觉 ID 对在短暂消失后于近处重现时桥接缺帧 | 训练校准；不得仅因框短暂消失而中断 |
| Snout-head contact | 鼻头到另一只鼠头部（鼻头/耳部）的几何接触 | 累计接触 ≥0.5 s |
| Snout-rear contact | 鼻头到另一只鼠尾部的几何接触 | 累计接触 ≥0.5 s |
| ［暂停 2026-10-04 Step 3］Following | 两鼠均表现 Walking、距离 5–30 cm、方向一致、无接触 | 3 s |

鼻头/鼻尾累计接触不足 0.5 s 不形成独立接触类别。Following 与 Chasing 分开：Following 要求行走且无逃跑/奔跑；Chasing 要求奔跑且无接触。Following/Avoiding 自 2026-10-04（Step 3）起暂停产出与标注，代码以 [SUSPENDED-STEP3] 标记保留。

## 群体行为

| 行为 | 判据 | 最短持续时间 |
|---|---|---:|
| Huddling | 至少 3 只；相邻边 = 鼻-鼻 ≤4.0125 cm 或中心 ≤8.025 cm（边缘鼠允许运动，群体内可有运动鼠）；无速度门；群体/track ID 关系稳定。检测框暂时缺失可桥接，需同一 ID 关系随后在附近恢复 | 5 s |

| Dispersal | 至少 3 只；片段先出现已聚集状态，随后邻接/最近邻距离持续增大（按适配器配置的增量/斜率门，导出路径增量默认为 ≥6.6875 cm），描述聚集群体散开 | 5 s |

## 训练与验证边界

候选行为规则使用训练集标签与目标 ID 来调整速度/空间阈值、阈值组合和排序系数；硬定义的最短持续时间不可被调低。训练集会报告拟合准确率和按录像 session 留出的内部结果。模型与规则锁定后，验证推理输入只包含匿名行号、轨迹路径和 FPS；预测 CSV 与哈希回执生成后才把验证标签用于计分。主指标是行为和标注目标 ID 完整集合同时正确的联合 Top‑1；群体预测多出或缺少成员 ID 都不算严格命中，成员覆盖率可另报。验证集标签不参与任何参数搜索。

自 2026-10-04（Step 3）起删除同层双标签计分：Together 新定义允许接触（无互动），Together↔接触的兼容信用不再需要，验证报告只列严格 Top‑1（预测目标 ID 集合必须与标注完全相同）。历史双标签数字仅属旧口径记录，不得与新口径混比。Snout-head 与 Snout-rear 仍不互认。

  群体仍须至少 3 只，并至少持续 1 s。静止个体层证据保留，但有效的社交或
  群体事件作为 primary 显示，不删除低层事件。
- 当时 Isolation 以目标到最近同伴的距离判定；调参候选范围为 15–50 cm，

- Together 与 Huddling 保持不同空间尺度：Together 使用 8 cm 双鼠阈值；Huddling 使用
  5 cm 群体紧密距离，并另需至少三只和低运动状态。两者不能互相代替。
- 按冻结后的训练内调参流程复跑：训练片段联合 Top-1 为 49.48%，录像 session
  留出为 45.10%；既有验证集轨迹-only 推理后，严格行为＋目标 ID Top-1 为
  40.51%（宏平均 39.53%）。验证逐类结果：Huddling 5/25（20.00%）、Together
