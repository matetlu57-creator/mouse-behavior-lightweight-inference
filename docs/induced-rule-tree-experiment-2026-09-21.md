# 人工标签诱导轨迹阈值规则实验（2026-09-21）

此实验使用原始训练集 679 条，包括此前因片段短于 5 秒而被临时隔离的
3 条 Social clustering 样本。它们有人工审核标签，短片段可能是较长事件的
截取；本实验未修改或剔除原始标注。指标仍为片段级联合 Top-1：
行为和完整视觉目标 ID 集合都正确。视觉 track_id 不被当成 RFID 动物身份。
已核对 679 条训练标注的事件区间均为片段第 0 帧至最后一帧；本实验使用这些
完整事件片段的轨迹，并没有因为上下文缺失再要求新的时间窗。

## 方法

训练入口 scripts/train_induced_rule_tree.py 只接受训练清单。从轨迹生成
16 个场景统计特征和每个视觉轨迹 32 个成员特征，不使用样本名、目录类别、
轨迹 ID 的数值或验证标签。人工审核的行为与目标 ID 用于训练三组显式阈值树：
场景轨迹到行为类别、群体行为目标成员数、以及每个视觉轨迹是否属于目标事件。

模型保存为可审计的 JSON 节点、阈值和叶值。推理只用轨迹、FPS 和已存在的
视觉 ID，自行输出一个行为与完整目标视觉 ID 集合；不建立或猜测稳定 animal_id。
深度 8、12 和不限制深度的训练内试验中，深度 12 是达到每类训练集 90% 的
较浅设置。深度 8 总训练准确率仅 73.34%；不限制深度得到 100%，但更易
记忆样本。

原录像场次轮流留出的预测在训练阶段单独计算。随后用全部训练样本重拟合，
冻结模型与源码哈希。验证命令没有拟合入口；它先仅用验证轨迹写预测 CSV，
生成 SHA-256 预测回执，才读取验证标签计分。既有验证集此前被评估过，
故这是既有验证集评估，不是全新未见过的测试集。

## 结论和边界

此方法满足“每个行为训练集准确率 ≥90%”的字面门槛，但未满足可迁移的
行为识别目标：独立录像场次与既有验证集都远低于训练集。深阈值树主要记住
了每个片段独特的全景统计和目标成员模式；它不是经验证有效的行为学规则。
本模型仅是实验性负面对照，不接入生产行为引擎，也不替换 v12 启发式基线。
不得用验证结果再选择树深度或改动本次已冻结模型，然后仍称其为盲测。

下一轮若继续优化，必须在训练集内部的录像场次留出上选择具有更强事件局部性
和跨场次稳定性的候选/特征，再用所有训练数据拟合。仅追求更高的训练集内
准确率会重演本次过拟合。
