# 北医 huddle 距离标定与全数据集重放

日期：2026-08-26

## 目的

本次只调整群体扎堆的空间阈值，目标是让北医四个 huddle 正向示例能够按照视频中
实际出现的距离被识别。推理逻辑不读取视频文件名或目录名，文件夹标签只用于重放
结束后的覆盖检查。

## 标定方法

四个正向 huddle 视频分别为 `群体-扎推1.mov` 至 `群体-扎推4.mov`。在每个视频中，
寻找持续至少 1 秒的局部三鼠核心，并计算该核心中所需的最大中心距离。四个样例
得到的稳定核心距离约为：

| 样例 | 稳定三鼠核心所需距离 |
| --- | ---: |
| 群体-扎推1 | 10.35 cm |
| 群体-扎推2 | 6.94 cm |
| 群体-扎推3 | 7.22 cm |
| 群体-扎推4 | 7.42 cm |

北医 profile 使用覆盖四个样例的统一上限 `11.0 cm`，将它定义为单条局部邻接边的
上限，不再叠加 `1.75` 倍体长二次上限。这样混合白鼠和黑鼠时，体型差异不会把固定
空间阈值错误缩小；大型 huddle 的远端对角成员也不需要彼此直接连边。

厘米换算仍使用同一视频共享的尺度，不按小鼠颜色或个体大小分别缩放。当前没有笼子
实际尺寸或静态相机标定，因此 `11.0 cm` 是基于体长参考的近似 profile 阈值；如果
后续获得可靠标定，应在 `scale.mode=fixed` 下提供统一的 `scale.cm_per_pixel`，再
重新验证四个正向样例。

## 运行规则

huddle 仍然必须满足以下条件：

- 至少 3 只真实观测到的小鼠；
- 每只核心成员至少有 2 个同组邻居；
- 局部邻居支持度至少为 0.5；
- huddle 使用局部 k-core，不要求核心内部形成全连接图；
- 成员集合稳定，不能把不同核心仅凭一个共同 ID 拼接；
- 核心证据至少持续 1 秒；
- 预测框 `bbox_imputed` 不会单独增加群体成员数；
- 两只小鼠接近仍然是社交行为，不会因为数量不足升级为 huddle。

## 重放方式

- 数据集：北医 39 个行为示例视频；
- 小鼠数：10；
- 抽帧：`sample_stride=1`；
- YOLO：复用已有 `yolo_precompute` 缓存，没有重复运行 YOLO；
- 结果目录：`<validation-output-root>/huddle_distance_calibrated/full`；
- 重放耗时：约 196.61 秒。

## 结果

四个 huddle 正向示例均达到持续时间门：

| 视频 | huddle 命中 | 最大核心持续时间 |
| --- | --- | ---: |
| 群体-扎推1 | 是 | 3.27 s |
| 群体-扎推2 | 是 | 1.00 s |
| 群体-扎推3 | 是 | 2.13 s |
| 群体-扎推4 | 是 | 3.00 s |

因此 huddle 的视频级覆盖由上一版的 `0/4` 提升到当前的 `4/4`。

同时，11 cm 阈值比原来的 5 cm 更宽。完整 39 个视频重放中，部分非 huddle 示例
也产生了满足当前三鼠几何门的局部核心。这说明当前北医目录是视频级重点行为标签，
不是逐帧负样本真值；要把这些共现核心进一步区分为“真正扎堆”或“社交行为经过”，
还需要逐帧标注的 huddle 起止时间和参与 ID。当前结果可以确认四个正向示例被召回，
不能据此宣称 huddle 的逐帧 Precision、Recall 或 F1 已经完成。
