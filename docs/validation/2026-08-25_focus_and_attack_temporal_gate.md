# 三类北医重点行为渲染与攻击时序门验证

日期：2026-08-25

## 本次变更

本次只针对追逐、回避和攻击三类北医重点样例做了两项改进：

1. 渲染器支持外部传入 `focus_behavior`。北医验证清单中的期望行为只用于右侧
   面板的持续重点标题，不参与事件推理，也不会根据视频名称或文件夹名称生成
   行为标签。
2. 攻击行为增加跨帧可靠性门。进入行为 CSV 的攻击至少需要两个分析样本在短
   时间窗口内相互支持。攻击峰值帧可以由邻近的高动态、接触和角色证据帧支持，
   但孤立单帧不会作为攻击导出或渲染。

## 解释边界

北医当前目录是视频级行为示例，不是逐帧真值。因此“真实事件公开覆盖超过 80%”
不能仅凭文件夹名称证明。当前实现保证的是重点复核提示覆盖 100%，同时不伪造
行为证据。若要把三类行为的实际逐帧事件覆盖率校准到 80% 以上，需要提供逐帧
起止时间和 actor、target 标注，再对时序阈值、追踪稳定性和召回率做有真值的
校准。
