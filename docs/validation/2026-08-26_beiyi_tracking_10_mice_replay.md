# 北医示例 10 鼠轨迹重放验证

日期：2026-08-26

## 背景

北医标注规范对应 RFID-CV 10 鼠实验。此前北医验证、规则重放和渲染入口沿用了通用 20 鼠默认值，使轨迹缓存为多余的逻辑小鼠预留了空槽位，也会降低后续配对几何计算的稳定性。

本次将北医入口的默认小鼠数改为 10。通用 20 鼠视频仍然可以通过命令行显式传入 20，不改变通用管线的使用方式。

## 验证方式

- 数据集：北医标注行为示例目录。
- 视频数量：39 个。
- 推理方式：复用已有 YOLO pose 缓存重放规则，没有重复运行 YOLO。
- 入口：`scripts/validate_beiyi_extended_ethogram.py`、`scripts/rerun_beiyi_lightweight_rules.py`、`scripts/render_beiyi_behavior_videos.py`。
- 参数：`expected_mice=10`、未规定行为持续至少 1 秒、孤立持续至少 3 秒。

## 结果

平均有效跟踪率由约 55% 提升到约 96%，说明小鼠数量配置确实是轨迹质量问题的一部分。

但是，仅修正小鼠数量不能让缺失的社交行为自动变成正确事件。当前重放结果仍显示：

| 行为 | 达到持续时间门的视频数 |
| --- | --- |
| running | 3/3 |
| walking | 3/3 |
| stationary | 3/3 |
| together | 3/4 |
| approach | 0/3 |
| chase | 0/3 |
| avoidance | 0/3 |
| attack | 0/3 |
| nose_head | 0/3 |
| nose_tail | 3/3 |
| huddle | 4/4 |
| isolation | 3/4 |

这表明当前剩余问题位于行为证据、角色方向、接触几何和时间连续性规则，而不是单纯的轨迹槽位数量问题。

## 下一步校准所需信息

视频文件夹名称只用于验证结果，不会参与推理分类。为了修正行为规则，需要从标注文件或视频中提供每个缺失行为的：

1. 行为发生的视频文件名。
2. 标注时间段或起止帧。
3. 行为主体和客体的小鼠 ID。对于鼻头、鼻尾和攻击，主体与客体方向尤其重要。
4. 如果标注文件没有 ID，需要说明该标注是否只表示“视频中存在该行为”。

有了这些真值后，可以逐段检查候选配对、距离、朝向、接触类型、FSM 状态和持续时间门，并用回归测试保护修正结果。

## 当前限制

当前验证器是视频级存在性检查，不是带主体、客体和时间区间的精确召回率计算。因此 `0/3` 只能说明最终持续时间过滤后的事件没有覆盖对应视频，不能单独证明模型完全没有产生任何候选证据。下一轮应使用标注时间段和小鼠 ID 进行帧级验证。
